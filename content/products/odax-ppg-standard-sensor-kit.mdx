## Overview

The **ODAX PPG Standard Sensor Kit** — **ODAX Reflective PPG Standard Sensor Kit - Sensor Board with Enclosure** — combines the [ODAX Reflective PPG Sensor](/products/odax-ppg-sensor) board with a black enclosure for reflective finger photoplethysmography (PPG) experiments.

The kit is based on the **ODAX-PPG-SR1-100-STD-R1** board. Its green optical emitters and photodiode sense changes in reflected light at the finger, while the analog front end conditions the signal and provides a filtered voltage output for a host ADC. Pulse detection and rate estimation are performed by your own firmware or software.

**Kit SKU / MPN:** `ODAX-PPG-SK1-100-BLK-R1`

## Kit Contents

1. **[ODAX Reflective PPG Sensor board](/products/odax-ppg-sensor)**. Board SKU / MPN: `ODAX-PPG-SR1-100-STD-R1`
2. **Black sensor enclosure** housing the PPG board

## The Sensor Board Inside

The [ODAX Reflective PPG Sensor](/products/odax-ppg-sensor), identified as **ODAX PPG Standard** in the datasheet, uses an **ams OSRAM BIOFY SFH 7072** optical module with two green emitters and an IR-cut photodiode. Its analog signal path converts photodiode current to voltage, suppresses the steady optical background, amplifies pulse variations, and filters the output.

| Board characteristic | Description |
|---|---|
| Board SKU / MPN | `ODAX-PPG-SR1-100-STD-R1` |
| Sensing method | Green reflective finger PPG |
| External supply, `VCC` | 3.0 V to 5.0 V design evaluation range; 3.3 V or 5.0 V nominal |
| Analog output, `VOUT` | Filtered waveform with a nominal settled baseline near 1.25 V |
| Host interface | High-impedance ADC input with a shared ground reference |
| Signal processing | Pulse detection and rate estimation performed by the host |

[View the ODAX Reflective PPG Sensor product page for full board specifications and connection details.](/products/odax-ppg-sensor)

## Getting Started

1. Review the [board datasheet](/datasheets/ODAX-PPG-SR1-100-STD-R1.pdf) and verify the actual cable connections to `VCC`, `GND`, and `VOUT` before applying power.
2. Connect `VOUT` to a high-impedance host ADC input and share the signal ground. Use a clean supply within the board's documented range and keep the output within the ADC's permitted input range.
3. Position the finger over the sensing area with light, consistent pressure. Support the hand and cable and shield the sensor from strong ambient light.
4. Allow the baseline to settle, then acquire and process the analog waveform using your host system.

See the [sensor board's getting-started guidance](/products/odax-ppg-sensor#getting-started) for acquisition and signal-interpretation details.
